# Лабораторная работа 4: построение бинарного дерева без рекурсии

Вариант **3**: корень `3`, высота `4`, левый потомок = значение родителя `+ 2`, правый потомок = значение родителя `* 3`.

## Состав проекта

- `binary_tree.py` — функция `gen_bin_tree` и пример альтернативного хранения дерева;
- `test_binary_tree.py` — тесты `unittest`;
- `.gitignore` — исключение служебных файлов Python.

## Запуск

Нужен Python 3.9 или новее. Дополнительные пакеты не требуются.

```bash
python3 binary_tree.py
python3 -m unittest -v
```

## Как устроено дерево

Каждый узел — словарь с ключами `value`, `left`, `right`. На последнем уровне оба потомка равны `None`. Корень считается первым уровнем, поэтому при высоте `4` дерево содержит 4 уровня и 15 узлов.

Функция строит дерево по уровням без рекурсии. Очередь `collections.deque` хранит пары `(узел, уровень)`. Для каждого узла создаются два потомка, пока не достигнута заданная высота. Значения по умолчанию задаются `lambda`-функциями. Можно передать свои значения и функции.

Дополнительно `tree_as_dict_of_lists` показывает другую форму хранения: словарь сопоставляет путь от корня (`L` — налево, `R` — направо) со значением узла и списком значений его потомков. Здесь тоже используется `deque` из модуля `collections`. Пути нужны, чтобы различать узлы с одинаковыми значениями.

## Пример

```python
from binary_tree import gen_bin_tree

tree = gen_bin_tree()
print(tree["value"])           # 3
print(tree["left"]["value"])   # 5
print(tree["right"]["value"])  # 9

other = gen_bin_tree(height=2, root=10,
                     left_leaf=lambda x: x - 1,
                     right_leaf=lambda x: x + 1)
print(other["left"]["value"])  # 9
```

## Проверка

Тесты проверяют вариант 3, высоту и количество узлов, замену всех параметров, частичную замену, недопустимую высоту и альтернативное представление.
